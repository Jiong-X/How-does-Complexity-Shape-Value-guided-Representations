Maze layouts, each file mapping a maze id to a list of row strings.

- `mazes_Lateralized.json`: the 12 original lateralized mazes (grid-000-l … grid-011-l)
- `mazes_Nonlateralized.json`: the 12 original non-lateralized mazes (grid-000-n … grid-011-n)
- `mazes_generated.json`: the 100 generated layouts (grid-012-l … grid-111-l)
- `mazes_sg_variants.json`: 100 start/goal variants of every layout (`<base_id>-SGxx`)

`.` free, `#` wall, `0`-`5` obstacles, `S` start, `G` goal.
